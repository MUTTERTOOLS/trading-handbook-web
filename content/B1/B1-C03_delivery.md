# B1-C03 交付说明（一道算术题：期望收益公式）

## ① 新术语（附一句话定义）

| 术语 | 一句话定义 | 首现位置 |
|---|---|---|
| 1R | 这笔交易事先计划好的亏损额（与"R 倍数"同条目引入，1.5 术语表口径：单笔计划亏损额，元） | 正文一 |
| R 倍数 | 盈亏金额 ÷ 1R，跨账户可比的记账单位 | 正文一 |
| 期望收益 | 同样的操作重复很多次后，平均每笔的预期得失（记作 E） | 正文二 |
| 胜率 | 盈利笔数 ÷ 总笔数（败率 = 1 − 胜率，随文定义，未单列术语） | 正文二 |
| 平均盈利 | 所有盈利笔的平均幅度（每笔百分比口径） | 正文二 |
| 平均亏损 | 所有亏损笔的平均幅度，代入公式取正数，须用真实值 | 正文二 |
| 摩擦成本 | 每笔买卖的佣金、印花税与价差损耗 | 正文二 |
| 盈亏比 | 平均盈利 ÷ 平均亏损 | 正文三 |
| 盈亏平衡胜率 | 不计成本时恰好打平所需胜率，p = 1 ÷ (1 + 盈亏比) | 正文三 |

（注：以上共 8 个条目，1R 并入"R 倍数"条目、败率随文定义，故 yaml new_terms 列 8 项。）

## ④ 已复算数字清单

- EX-E：0.8×2%=1.6%；0.2×10%=2.0%；E=−0.4%/笔；交叉核对：盈亏比 0.2 → 平衡胜率 1÷1.2≈83.3%＞80%，应为负，一致。
- EX-F：0.4×6%=2.4%；0.6×2%=1.2%；E=+1.2%；含成本 +1.0%；交叉核对：盈亏比 3 → 平衡 25%＜40%，应为正，一致。
- EX-G：0.65×4%=2.6%；0.35×8%=2.8%；E=−0.2%；交叉核对：盈亏比 0.5 → 平衡 66.7%＞65%，应为负，一致。
- 平衡表：1÷1.5≈66.7%；1÷2=50%；1÷3≈33.3%；1÷4=25%；1÷6≈16.7%。
- R 单位算例（独立示意）：0.5×2R−0.5×1R−0.05R=+0.45R/笔（即 450 元）；百分比口径核对 0.5×2%−0.5×1%−0.05%=+0.45%，一致；盈亏比 2 → 平衡 33.3%＜50%，应为正，一致。
- 安全边际：EX-F 40%−25%=15 个百分点；EX-G 65%−66.7%=−1.7 个百分点。
- 题 2（甲）：0.9%−0.2%=+0.7%；盈亏比≈3.33 → 平衡≈23.1%。
- 题 3（乙）：−0.1%−0.2%=−0.3%；盈亏比 0.4 → 平衡≈71.4%。
- 题 4（丙）：+0.5%−0.2%=+0.3%；盈亏比≈1.33 → 平衡≈42.9%。
- 题 1（R 换算）：2400÷800=+3R；400÷800=−0.5R；800÷800=+1R。
- "成本削掉六分之一"：0.2÷1.2=1/6。
