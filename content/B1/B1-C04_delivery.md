# B1-C04 交付说明（"5+1"信息分类：风、时、价、量、仓、心）

## ① 新术语（附一句话定义）

| 术语 | 一句话定义 | 首现位置 |
|---|---|---|
| 5+1 信息分类 | 风、时、价、量、仓、心六类信息加单列成本 C 的统一分类称呼（全书统一称呼，不用"六元/原子"） | 正文二 |
| 风 | 宏观、行业、公司、政策与新闻类外部信息的统称 | 正文二 |
| 时 | 时间与周期坐标：日线位置、距重要事件远近、市场阶段 | 正文二 |
| 价 | 价格本身与所处位置：现价、近期高低点、相对基准的贵贱 | 正文二 |
| 量 | 参与热度与分歧：成交量、成交额等 | 正文二 |
| 仓 | 头寸与资金管理：买多少、占多大、最多亏多少、怎么退出 | 正文二 |
| 心 | 执行残差：实际执行与书面计划之间的差距（非独立原子） | 正文二 |
| 成本 C | 每次买卖要付的钱（佣金、印花税、价差等），单列不并入六字 | 正文二 |

（注："执行残差"作为"心"的定义内嵌出现并加粗，未单列 new_terms 条目，故共 8 项。）
