# B3-C08 交付说明（胜率、赔率、频率的配平）

## ① 新术语（附一句话定义）

| 新术语 | 一句话定义 |
|---|---|
| 盈亏比 | 每承担一分平均亏损，平均能换回几分盈利；统计口径 = 平均盈利 ÷ 平均亏损（1.6 另有计划口径公式） |
| 盈亏平衡胜率 | 让单笔期望恰好为零所需的胜率，p = 1 ÷（1 + 盈亏比）（不计成本；B1-C03 引入，册三首次出现于本章，按 1.8 加粗定义） |
| 盈亏平衡曲线 | 盈亏比与盈亏平衡胜率的对应曲线，p = 1 ÷（1 + 盈亏比），左高右低 |
| 含成本盈亏平衡胜率 | 计入每笔成本后的及格线 =（平均亏损 + 成本）÷（平均盈利 + 平均亏损） |
| 配平 | 调整胜率、盈亏比、频率三个量，使组合后单笔期望为正并留有余量的过程（六条风控骨架之五） |
| 尾部亏损 | 偏离平均值很远的少数极端亏损，常见来源为跳空、一字跌停、停牌或未按规则退出 |
| 实际/计划亏损比 | 实际平均亏损 ÷ 计划亏损，衡量计划亏损被现实打穿的程度 |

注：七个术语均首次出现即加粗并附定义，写法与 1.5 一致（"盈亏平衡胜率"按 1.6 公式写；未用"六元/原子"；门派只用 B/C/E）。

## ④ 已复算数字清单（均二次复算）

## ⑧ 偏离说明

1. **"含成本盈亏平衡胜率"公式为新增**：Bible 1.6 只列了不计成本的 p = 1 ÷（1 + 盈亏比）。本章公式 (L+c)/(W+L) 是其直接推论，已给出双路推导与交叉验证。建议总编考虑纳入 1.6 公式表，避免后册各写各的。
2. **判读线（1.0~1.1 / 1.1~1.2 / >1.2、单笔 3R 复盘线）为本章独立示意新增**，未用"起步参考值"名义以免混入 1.6 常量表；请总编确认保留、修改或删除。
3. **标题与术语用词**：章规格与标题用"赔率"，正文按 1.5 统一写"盈亏比"，并加一句说明（标题保留规格原文）。
4. **三风格典型区间**（35~45%、2~3）为章规格"必含"原文，正文按红线 8 加注"示意区间，非标准"。
5. 速查卡小节标题沿用样章 B3-C04 先例写"## 速查卡"（1.7 模板中"速查卡 / 检查清单"按菜单理解）。
6. **篇幅**：正文 4,377 字符合"4,000~6,000"；全文 7,616 字（含标点、数字串口径）略超"册三重点章可到 7,000"。超出约 9% 来自规格必含体量：4 组策略判断练习各附逐步解析、5 题自测、盈亏平衡曲线完整绘图说明。如总编要求压回 7,000 内，建议压缩速查卡与延伸链接，正文勿动。
