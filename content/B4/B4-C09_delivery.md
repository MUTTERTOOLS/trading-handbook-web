# B4-C09 交付说明（指标组合：不超过三个信号）

## ① 新术语

| 术语 | 本章定义（首现位置） |
|---|---|
| 信号类指标 | 写入规则、用于产生"可以考虑入场或离场"判断的指标（正文一） |
| 同源指标 | 由同一份原始数据计算出来的指标（正文二） |
| 指标冗余 | 多个信号类指标高度同源、回答近似问题，信息未增加（正文二） |
| 假多样性 | 同源多指标同时成立、同时失效造成的"多重确认"错觉（正文二） |
| 互补原则 | 组合内信号应原始数据不同、回答问题不同、失效不重叠（正文三） |
| 过拟合 | 规则对历史数据过度适配、未来难以延续的状态（正文四；前向链接〔B6-C01〕〔B6-C08〕） |
| 均值回归 | 价格偏离区间中轴后向区间内拉回的倾向，限震荡状态下谈论（正文三） |

共 7 个，未超 8 个上限；全部为首次出现加粗并附一句话定义。
