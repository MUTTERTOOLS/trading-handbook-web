## 开场问题

周二早上 9:15，小明在纸上写了三条计划：甲股份到 10.20 就买、止损 9.70、买 1,800 股。9:40，群里有人说丙股份（虚构）今天有"大动作"，他看了一眼，涨得确实快，先追了半仓。10:30，甲股份真的到了 10.20，他又觉得"涨这么多别追高"，没买。收盘甲股份 10.45，小明两头落空，还搭上丙股份的浮亏。

计划没有失效——计划根本没有被执行。问题出在哪？出在计划只存在于"早上 9:15 的小明"脑子里，而盘中做决定的是"上午 10:30 的小明"。本章的任务，是把计划变成一把锁。

## 一句话结论

**计划写于盘前、存档不可改：触发不出现就不做，盘中只执行已写好的动作。**

## 本章学习目标

1. 能独立填写十个字段的盘前快照，并完成总风险检查。
2. 能对照合格与不合格示例，指出缺失字段及对应的盘中风险。
3. 能执行"写完即存、不可修改"的存档流程，并说出盘中允许与禁止事项。

## 正文

### 一、为什么把计划"锁"在开盘前

盘前和盘中，你掌握的信息几乎一样，差别在情绪负荷。盘前没有持仓波动、没有群消息、没有分时图的拉扯；盘中每一秒都有新的诱惑与恐惧。上一章说过，弱点攻击的正是盘中决策（〔B7-C02〕）。所以可靠的做法不是"盘中提醒自己冷静"，而是**把全部决策提前到盘前完成，盘中只留执行**。

这正是〔B3-C03〕五步顺序的落地形式：看环境、选结构、算止损与仓位、等触发、盘后对账——五步在开盘前全部走完并写成文字，开盘后只做两件事：监控触发、按章执行。五步的详细讲解在归属章，本章不复述，只提供它的书面容器。

**盘前快照**：开盘前写好的、包含固定字段的当日交易计划记录。**盘前快照锁**：围绕快照的一套执行制度——写完即存、盘中不可修改、不触发则不做。

**打个比方。**航班起飞前，机组照检查单逐项核对，核对完签字。飞行途中遇到情况，按预案处置，而不是现场发明预案。

*类比的局限：* 飞行预案覆盖的情形经过长期积累，环境相对封闭；市场每天出现新信息，所以快照之外还配"盘中允许与禁止清单"，并对客观突发事件留出规则化处理口（见第五节）。

快照不预测行情。它的每一行都是"如果……那么……"：如果触发条件出现，那么按写好的价格与股数执行；如果不出现，那么不交易。写快照的过程，就是把〔B3-C03〕的五步与〔B3-C04〕的仓位公式亲手走一遍的过程。

### 二、模板：十个字段

| 字段 | 写什么（一句话说明） |
|---|---|
| 1 日期时间 | 写下快照的日期与时刻，作为存档时间戳。 |
| 2 环境判断 | 用事先写好的环境规则给今天定级（如基准指数在 60 日线上方或下方）；过滤器本身的定义详见下章〔B7-C05〕。 |
| 3 标的 | 只写标的池内的名字与代码，池外品种今天不讨论。 |
| 4 触发条件 | 客观可观察的入场触发（价格、量、确认方式），精确到数字，不含"感觉差不多"。 |
| 5 入场价与股数 | 按仓位公式算好的价格与股数（〔B3-C04〕），写死，盘中不改。 |
| 6 止损价 | 由买入逻辑失效点决定（〔B3-C05〕），触发即执行，不允许"到时候看"。 |
| 7 退出条件 | 止损以外的退出（目标价、跟踪条件等），对应七种退出（〔B3-C09〕）。 |
| 8 时间止损日 | 到某日仍未触发止损也未达到退出条件，就按时间止损离场。 |
| 9 总风险检查 | 本笔 1R、实际计划亏损、加上本笔后在途总风险是否仍在上限内（〔B3-C04〕、〔B3-C07〕）。 |
| 10 不触发则不做 | 声明行：触发条件不出现，当天不交易该标的，也不临时换标的。 |

**触发条件**：入场信号被明确定义后形成的那句客观陈述，是快照的开关。**时间止损日**：为"既不涨也不跌"的横盘情形预设的离场日期，对应七种退出中的时间止损（〔B3-C09〕）。

十个字段缺一不可，因为缺的每一格都会在盘中变成一个弱点入口：没有触发条件，盘中就会"感觉到了"就买（FOMO，〔B7-C02〕）；没有止损价，亏损就会"到时候看"（扛单）；没有股数，仓位由情绪决定（过度自信）；没有总风险检查，在途风险悄悄超限（〔B3-C07〕）；没有时间止损日，资金被无限期占用（沉没成本）；没有第十行，前九行都可能被盘中推翻。

### 三、一份合格示例（EX-B 参数）

以下示例沿用统一算例（EX-A 账户、EX-B 风险参数；触发与退出细节为独立示意）：

```
【盘前快照】
日期时间：2024-05-20 08:45（示意）
环境判断：基准指数收盘在 60 日线上方 → 按我的环境规则 A，总风险上限取正常档（规则内容详见下章〔B7-C05〕）
标的：甲股份（虚构示意，非推荐）
触发条件：盘中成交价 ≥ 10.20 元，且当日成交量高于前 20 日平均量（示意阈值）
入场价与股数：10.20 元附近限价买入 1,800 股
  （1R = 100,000 × 1% = 1,000 元，1% 为起步参考值，需个人校准；
    每股风险 = 10.20 − 9.70 + 0.05 = 0.55 元；
    1,000 ÷ 0.55 ≈ 1,818 股 → 向下取整为 1,800 股）
止损价：9.70 元（买入逻辑：站上前期平台；跌回平台内即逻辑失效）
退出条件：达到 11.30 元（约 +2R）卖出半仓，其余按跟踪规则；收盘跌破 60 日线清仓
时间止损日：入场日起第 10 个交易日收盘前（若 2024-05-20 入场即 2024-05-31；若次日入场即 2024-06-03；日历为示意）
总风险检查：本笔实际计划亏损 = 1,800 × 0.55 = 990 元；已有持仓在途计划亏损合计 3,000 元；
  合计 3,990 元 ≈ 3.99% ≤ 5%（起步参考值，需个人校准）→ 通过
不触发则不做：今日触发条件未出现，则不买甲股份，也不买任何标的池外品种
```

三处数字核对一下。其一，每股风险 10.20 − 9.70 + 0.05 = 0.55 元。其二，股数 1,000 ÷ 0.55 ≈ 1,818.2，向下取整到 1,800 股；买入金额 1,800 × 10.20 = 18,360 元，占本金 18.36%，在单票上限 20% 之内（起步参考值）；实际计划亏损 990 元，未超 1R。其三，总风险检查 3,000 + 990 = 3,990 元，占本金约 3.99%，未超 5% 上限。三项全部通过，快照才允许存档。

+2R 退出价的口径：入场 10.20 元、每股风险 0.55 元，2R 对应 10.20 + 2 × 0.55 = 11.30 元。价格目标写在触发前的盘前时段，不由盘中情绪顺口报出。

### 四、一份不合格示例：差在哪

同一个标的、同一天，另一份"计划"长这样：

```
【今日打算】（不合格示例）
标的：甲股份，感觉要突破了
触发：涨上去就买，越强越好
止损：心里有数，到时候看
股数：先买点试试，不行再加
退出：赚了就走
风险：应该问题不大
```

它的问题不是格式难看，而是每一格都留了一个盘中决策口。逐行对照：

| 不合格写法 | 缺了什么 | 盘中会变成什么 |
|---|---|---|
| "感觉要突破了""涨上去就买，越强越好" | 无客观触发条件与价格数字 | 感觉一到就追，越急追得越高（FOMO 入口） |
| "止损到时候看" | 无止损价 | 亏损扩大后更难下手（扛单入口） |
| "先买点试试，不行再加" | 无股数，含加仓预案 | 仓位由情绪决定，滑向亏损加仓〔B3-C02〕 |
| "赚了就走" | 无"赚多少"的定义 | 拿不住盈利（处置效应入口） |
| "应该问题不大" | 无总风险检查 | 在途风险可能悄悄超限〔B3-C07〕 |
| 全文无时间戳存档 | 不可对照 | 盘中改口后无证据，归因失效〔B7-C01〕 |

合格与不合格的分界线只有一条：**盘中是否还剩"需要临场决定"的事**。合格快照把所有决定前置，不合格快照把决定全部留给盘中那个情绪最满的自己。

### 五、时间戳与存档：让快照成为证据

快照的价值一半在"写"，一半在"存"。存档规则三条。

1. **写完即存。**存档动作在开盘前完成，带时间戳。开盘后再写的不算盘前快照。
2. **不可修改。**已存档的快照不允许覆盖或编辑。盘中确实出现客观事件（如临时停牌、重大公告）需要调整计划的，另存一份带新时间戳的"变更记录"，注明原因，原快照保留。变更走的是"新增记录"，不是"改旧文件"。
3. **复盘时找得回。**保存方式建议截图或导出文件，具体用什么工具本书不指定；要求只有三条：有时间戳、不可覆盖、月底复盘时能批量取回（记账与月度复盘见〔B7-C07〕）。

为什么要这么较真？因为快照是三类归因的第一证据（〔B7-C01〕）：没有存档快照，"违没违规"就只剩各说各话；影子账户的逐笔核对也要以快照为基准（〔B7-C04〕）。快照不是写给市场看的，是写给两周后复盘的自己看的。

**打个比方。**快递单号的意义在于"揽收时刻有记录"。没有单号，包裹丢没丢就成了一笔糊涂账。

*类比的局限：* 快递丢件有第三方裁决；交易的争议双方是现在的你与复盘时的你，所以存档必须由你自己事前建立。

### 六、盘中允许与禁止事项清单

快照锁住计划，清单锁住行为。以下清单随快照一起存档。

**允许做的事：**
1. 监控触发条件是否出现（可用券商条件单辅助，但条件单依赖券商系统，跳空、跌停等情形可能不触发或不成交，〔B2-C03〕）。
2. 触发出现后，按快照写明的价格与股数执行。
3. 止损价、退出条件、时间止损日触发时，按快照执行。
4. 记录实际成交价与滑点，供记账使用。
5. 出现客观突发事件时，按事先写好的规则处理并记录；没有对应规则的，按"不做"处理，盘后补规则。

**禁止做的事：**
1. 修改或覆盖已存档快照。
2. 交易快照之外的标的。
3. 触发条件未出现时提前入场。
4. 放宽、下移或取消止损。
5. 因盘中消息临时加大股数或加仓。
6. 未到退出条件而"手痒"离场。
7. 熔断触发后继续开新仓（〔B3-C10〕；连败期行为细则见〔B7-C06〕）。

清单的记忆口诀只有一句：**盘中只做快照里写过的动作，其余一律记违规。**违规但盈利同样记偏差（〔B7-C04〕），因为这一次的盈利会让下一次的违规更难拒绝。

## 常见误区

**误区一："计划在我脑子里，何必写下来。"**
- **为什么错：** 脑内计划没有时间戳、无法对照、可以在盘中被无声改写。复盘时你说"我本来打算 9.70 止损"，没有任何证据；三类归因第一步就走不动（〔B7-C01〕）。
- **正确做法：** 写、存、锁：盘前写完、带时间戳存档、盘中不修改。

**误区二："盘中市场变了，计划当然要跟着变。"**
- **为什么错：** 盘中的"市场变了"，多数是情绪给旧信息贴了新标签；真正的环境变化应当由事先写好的规则捕捉（环境过滤器，详见下章〔B7-C05〕），而不是靠临场判断。任何规则改动都必须重新验证后才能上线（后文〔B8-C09〕详述）。
- **正确做法：** 变更走"另存变更记录"，注明客观原因；定期把反复出现的变更提炼成规则，重新验证后再进快照。

**误区三："我挂了条件单，等于已经锁好了。"**
- **为什么错：** 条件单是工具，不是制度。它依赖券商系统，遇到跳空、一字跌停、停牌可能不触发或不成交（〔B2-C03〕）；挂了条件单再手动撤掉，也是常见违规。把工具当制度，会漏掉"人"这个环节。
- **正确做法：** 快照锁是行为制度：快照存档在先，条件单只是执行手段之一，成交与否都要回填记账。

## 本章小结

1. 盘前快照是五步决策顺序（〔B3-C03〕）的书面容器，盘中只留执行。
2. 十个字段缺一不可：缺的每一格都是盘中一个弱点入口。
3. 合格标准只有一条：盘中不剩需要临场决定的事。
4. 存档三规则：写完即存、不可修改、复盘找得回；变更走另存记录，不改原文件。
5. 盘中口诀：只做快照里写过的动作，其余一律记违规。

## 自测题

**题 1（字段）。** 快照缺"时间止损日"会带来什么后果？它对应七种退出中的哪一种？

**答案与解析：** 买入后既不触发止损也达不到退出条件的横盘情形没有离场日期，资金被无限期占用，而且横盘数周后容易"顺手"改成套牢长线。它对应七种合法退出中的时间止损（〔B3-C09〕）。

**题 2（总风险检查）。** 本金 100,000 元，已有 3 笔持仓的在途计划亏损分别为 1,100、900、1,500 元。今日快照按 EX-B 口径算出本笔实际计划亏损 990 元。总风险检查通过吗？（数字为独立示意）

**答案与解析：** 1,100 + 900 + 1,500 = 3,500 元；加本笔 990 元，合计 4,490 元，占本金约 4.49%，未超 5% 上限（起步参考值），通过。注意快照里必须写实际计算值 990 元，而不是取整的 1,000 元：总风险检查核对的是实际计划亏损。同板块持仓需合并计算（〔B3-C07〕）。

**题 3（判断）。** "盘中出了利好，先按新信息买入，收盘后再补一份快照就行。"这句话错在哪？

**答案与解析：** 两处错。其一，开盘后写的不算盘前快照，没有"锁"的效力；其二，这是快照之外的动作，属于无信号交易违规。盘中允许清单里没有"根据新信息临时买入"这一项；没有对应规则的突发事件，按"不做"处理，盘后把该情形写成规则、重新验证后再进快照（后文〔B8-C09〕详述）。

**题 4（对照）。** 下列三句摘自某快照，逐句判断合格与否并说明理由："① 止损：跌破昨日低点即卖出；② 股数：看盘中量能，强就多买些；③ 退出：达到 11.30 元卖出半仓，或收盘跌破 60 日线清仓。"

**答案与解析：** ① 基本合格，但"昨日低点"必须在快照里写出具体数值。② 不合格：股数必须由仓位公式算出并写死（〔B3-C04〕），"看量能定股数"把仓位决定权交回了盘中。③ 合格：退出条件可观察、可执行，分别对应七种退出中的目标止盈与逻辑证伪。

**题 5（练习：写一份合格快照）。** 虚构情景：本金 100,000 元，单笔风险 1%；标的为乙 ETF（虚构），现价 2.00 元；买入逻辑为"突破箱体上沿 2.05 元"，上沿失守即逻辑失效，止损价 1.95 元，滑点缓冲取 0.01 元；目标约 +1.5R；时间止损为入场后第 5 个交易日；已有持仓在途计划亏损合计 2,000 元。请写出一份合格的盘前快照。

**答案与解析（参考答案，数字为独立示意）：**

```
【盘前快照】
日期时间：2024-05-20 08:50（示意）
环境判断：基准指数收盘在 60 日线上方 → 按环境规则 A，总风险上限取正常档（规则内容详见下章〔B7-C05〕）
标的：乙 ETF（虚构示意，非推荐）
触发条件：盘中成交价 ≥ 2.05 元（箱体上沿突破；收盘确认或盘中触发，二选一须事先定死）
入场价与股数：2.05 元附近限价买入 9,000 份
  （1R = 100,000 × 1% = 1,000 元；
    每股风险 = 2.05 − 1.95 + 0.01 = 0.11 元；
    1,000 ÷ 0.11 ≈ 9,091 份 → 向下取整到最小单位为 9,000 份）
止损价：1.95 元（箱体上沿失守即逻辑失效）
退出条件：达到 2.22 元卖出全部（+1.5R：2.05 + 1.5 × 0.11 ≈ 2.22）
时间止损日：入场日起第 5 个交易日收盘前
总风险检查：本笔实际计划亏损 = 9,000 × 0.11 = 990 元；买入金额 9,000 × 2.05 = 18,450 元，
  占 18.45% ≤ 20%；在途 2,000 + 990 = 2,990 元 ≈ 2.99% ≤ 5% → 通过
不触发则不做：触发未出现，当日不交易乙 ETF，也不交易池外品种
```

评分要点：其一，触发条件含具体数字；其二，股数有计算过程，实际计划亏损 990 元不超 1R；其三，总风险检查两项齐全；其四，有"不触发则不做"声明行。股数核对：1,000 ÷ 0.11 ≈ 9,090.9，向下取整到最小单位 100 份为 9,000 份（场内基金最小交易单位见〔B2-C04〕，【待核验】此处不展开）。
