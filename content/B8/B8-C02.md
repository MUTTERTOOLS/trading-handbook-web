## 开场问题

小明按上一章把学习线与实盘线分开（〔B8-C01〕），学习线的第一站是收集。一周下来，他收到三种声音：

群里有人说："三买确认，主力进场，目标前高，跟上。"

朋友推荐："ETF 网格，跌了买、涨了卖，听说是震荡市里舒服的活儿。"

书上写着："每月固定日子买入宽基指数，长期持有。"

三种说法都通顺，都有一批拥护者，格式却完全不同：一个是话术，一个是工具，一个是纪律。放在一张桌子上比较，需要统一的格式。

本章给这个格式：一张九个字段的卡片。任何流派，填进九格之后，逻辑通不通、缺什么件、证据几级，都摆在纸面上。

## 一句话结论

**拆解卡用九个字段把任何流派放进同一格式；填得满不等于有效，字段缺失与证据强度才是答案。**

## 本章学习目标

1. 能背出拆解卡的九个字段，说出每个字段回答的问题与填写规范。
2. 能独立为一个门派填出完整拆解卡，并写出证据强度（A–D）的定级理由。
3. 能用九字段检查一段方法描述，指出缺失字段与红旗字段。

## 正文

### 一、一张卡片，一个格式

**拆解卡**是用九个固定字段描述一个流派的格式化表格。按本丛书的概念归属，对拆解卡的深讲只在本章，其他章节只引用。

先限定标题里"看穿"两个字：拆解卡看穿的是结构，不是盈亏。它回答"这个方法靠什么逻辑、用了哪些信息、怎么控风险、怎么退出、证据几级"，它不回答"接下来会不会赚钱"——后者只有验证能回答（〔B6-C12〕）。

**打个比方。** 拆解卡像海关申报单：入境者必须逐项申报，漏报和虚报的那一格，往往就是问题所在。

*类比的局限：* 申报单核对的是既成事实，拆解卡里有几格是判断（如证据强度、适配），要按册六的标准填，不能凭印象。

使用纪律先立两条。第一，一页纸：超过一页，说明你在抄资料，不是在拆解。第二，卡片填满不构成推荐：第九格之前的一切都只是描述，"与我的适配"也只是事实核对，都不是下单理由。

### 二、九个字段逐个讲

**①收益来源（含对手盘）。** 回答：这个方法赚的是哪一类钱。规范：只能从五类收益来源（〔B1-C02〕）里选，并写出对手盘是谁、对方为什么会持续"让"出这部分钱。写不出来源，或写成"主力资金""庄家动向"这类无法核验的说法，按〔B1-C02〕的规则处理：说不清收益来源，则不采信。常见填错：把"历史回测漂亮"当来源——那是证据，不是来源。

**②5+1 调用。** 回答：方法用到了 5+1 信息分类（〔B1-C04〕）里的哪几格。规范：逐格写"用了/未用"，未用的格子也要如实写"未用"；成本 C 单列。既不看价、也不看量、也不看时的方法，不是方法，是感受。常见填错：把没用的格子写成"通用"。

**③配平方式。** 回答：胜率、赔率、频率三者怎么搭（〔B3-C08〕）。规范：写出大概形态（如低胜率高盈亏比）与数字区间，数字必须来自方法自己的统计或可核验的公开记录，不能抄宣传语。常见填错：只写胜率不写赔率——高胜率照样可以对应负期望（〔B3-C08〕的 EX-E 情形）。

**④风控方式。** 回答：这个门派自带什么仓位与止损逻辑。规范：有则写，没有就写"无——由手册补齐"，不许空着；手册参数永远以册三为准（〔B8-C01〕分工表）。常见填错：把"建议半仓"当风控——仓位比例与亏损预算是两回事。

**⑤退出条件。** 回答：持仓怎么离场。规范：把门派的每条退出映射到七种合法退出（〔B3-C09〕）并写编号；⑥熔断强制减仓/平仓与⑦账户外现金需求是任何门派都要带的共同条款。一条退出都写不出的方法，直接红旗。

**⑥证据强度。** 回答：我们凭什么相信它有效。规范：按 A–D 分级填写，分级深讲在〔B6-C04〕：A＝机械规则＋样本外通过＋成本已计入；B＝机械规则，样本外不足或无；C＝检查表＋决策日志的自由裁量型，上限 C；D＝故事、个案、口述。宣传话术默认填 D，除非对方给出可核验记录。

**⑦成本与容量。** 回答：费用和规模会不会毁掉它。成本按〔B2-C05〕口径逐项过；**容量**指方法能承载的资金规模上限——资金量大到一定程度，进出本身会推动价格，滑点上升，容量估算口径见〔B4-C07〕（比例类数字需核验或标示意）。常见填错：低赔率高频方法漏算费用——费用对它的杀伤比对低频方法大一个量级。

**⑧失效条件。** 回答：什么情况下这个方法的逻辑前提被破坏。规范：写成可观察的描述，并与〔B6-C11〕的停用判据挂钩。写不出失效条件的方法等于无法停用，只能亏到疼才停。

**⑨与我的适配。** 回答：它与我的事实是否匹配。规范：只写事实（作息、资金量与期限、性格、回撤承受），不写愿望；判定标准在〔B8-C08〕的四个问题。常见填错：把"我想赚钱"当适配。

九个字段的模板汇总如下表。

**拆解卡九字段模板表**

| 字段 | 回答的问题 | 填写规范（一句话） |
|---|---|---|
| ①收益来源 | 赚哪一类钱 | 五类来源选一，写清对手盘；写不出则不采信 |
| ②5+1 调用 | 用了哪些信息格 | 逐格写"用了/未用"，成本 C 单列 |
| ③配平方式 | 胜率赔率频率怎么搭 | 写形态与区间，数字须有出处 |
| ④风控方式 | 自带什么仓位止损逻辑 | 有则写，无则"由手册补齐"；参数以册三为准 |
| ⑤退出条件 | 怎么离场 | 映射七种退出并写编号；⑥⑦为共同条款 |
| ⑥证据强度 | 凭什么信它有效 | 按 A–D 填，宣传话术默认 D |
| ⑦成本与容量 | 费用与规模的杀伤 | 成本逐项过；容量写约束 |
| ⑧失效条件 | 前提何时被破坏 | 写成可观察描述，挂停用判据 |
| ⑨与我的适配 | 与我的事实是否匹配 | 只写事实，判定看四问（〔B8-C08〕） |

### 三、示范卡：门派 C（中线趋势跟踪）

选门派 C 做示范，因为它字段最全：有明确的入场、止损、退出与配平形态，适合第一次学填卡。下面的参数与〔B8-C05〕的一页纸规则完全一致；按全册定位句（〔B8-C01〕），它们全部是待验证假设，未经册六流程验证。

**门派 C 拆解卡（示范）**

| 字段 | 门派 C 的填写 |
|---|---|
| ①收益来源 | 行为偏差（反应不足形成的动量）。对手盘：对新信息反应偏慢的交易者，以及到期或回撤时被迫按规则卖出的资金。 |
| ②5+1 调用 | 价（20 日新高、60 日线）；量（20 日均量 1.2 倍确认）；时（20 日窗口、20 个交易日期限）；风（环境过滤器看基准指数状态，最小化使用）；仓（方法不定仓位，由手册 1R 公式定）；心（按册七流程）；成本 C（佣金与滑点计入）。核心格：价与量。 |
| ③配平方式 | 低胜率、高盈亏比、中低频率。位置参考〔B3-C08〕：趋势型约 35%~45% 胜率、盈亏比 2~3 以上；形态近 EX-F（胜率 40%、平均盈利 6%、平均亏损 2%，扣成本约 +1.0%/笔）。区间数字为位置示意，实际以自己的交易统计为准。 |
| ④风控方式 | 信号性止损＝入场价−2×ATR(14)（ATR 构造见〔B4-C07〕）；仓位按〔B3-C04〕公式反推，单笔风险 0.5%~1%（起步参考值，需个人校准）；环境过滤器：基准指数在 60 日线下方时，总风险上限减半（事前规则，〔B7-C05〕）。 |
| ⑤退出条件 | ①开仓逻辑被证伪（跟踪止盈）：收盘跌破 20 日低点或 60 日线；③时间止损：持仓超过 20 个交易日未达 +0.5R 即退出；⑥熔断强制减仓/平仓与⑦账户外现金需求为共同条款（〔B3-C09〕）。不使用②④。 |
| ⑥证据强度 | 当前填 B：机械规则、结构完整，但示例参数未经样本外检验。走完〔B6-C12〕九步且样本外通过、成本计入后，才可升 A。 |
| ⑦成本与容量 | 中低频，费用影响小于高频方法，按〔B2-C05〕口径计入；标的限流动性好的宽基/行业 ETF；容量约束＝单笔成交不超过标的日均成交额的一定比例（口径见〔B4-C07〕，比例数字需核验或标示意）。 |
| ⑧失效条件 | 价格延续倾向消失：基准指数长期处于 60 日线下方（过滤器长期生效）、新高信号频繁立即失败、磨损明显放大。停用判据三要素见〔B6-C11〕。 |
| ⑨与我的适配 | 待读者作答的四问：能否接受连续多次 −1R 不变形；能否接受数月无信号；资金期限是否匹配；回撤承受与 H 的校准是否一致（判定标准见〔B8-C08〕）。 |

示范卡读完，回到定位句：这张卡填得整齐，不代表门派 C 有效，只代表门派 C 可被检验。可检验是有效的必要条件，不是充分条件。

### 四、练习：给一段虚构带单话术填卡

以下文字为完全虚构的练习材料，不针对任何真实流派、真实人物或真实方法体系；其中术语的用法也不代表任何真实体系的准确表述。

> "各位家人，今天 30 分钟级别中枢完成，三买确认，配合背驰修复，主力资金已经进场。目标看到前高上方，止损放在中枢下沿。仓位先上五成，对了加仓，错了补仓摊成本。跟上的家人今晚复盘见。"

请按九字段给这段话术填卡，再对照参考答案。

**参考答案**

| 字段 | 参考答案 |
|---|---|
| ①收益来源 | 写不出。"主力资金进场"不在五类来源之内，也无法核验——按〔B1-C02〕规则：不采信。 |
| ②5+1 调用 | 只沾价（中枢、前高）；量、时、风未用；仓只有"五成"这个孤数；心只有"复盘见"三个字；成本 C 只字未提。 |
| ③配平方式 | 无任何数据。"对了加仓、错了补仓"还会改写配平结构——亏损加仓属于〔B3-C02〕列出的破产结构之一。 |
| ④风控方式 | "五成"与止损价之间没有换算关系，不是按 1R 反推的仓位；"补仓摊成本"会放大单笔风险，抵触手册参数。 |
| ⑤退出条件 | "目标前高上方"勉强算②边际赔率恶化（目标止盈），但目标价模糊；"中枢下沿"未说哪个中枢、按收盘还是盘中触发；无时间止损；⑥⑦未提。 |
| ⑥证据强度 | D：口述，无规则、无记录、无验证。 |
| ⑦成本与容量 | 补仓与频繁带单会推高费用（〔B2-C05〕口径）；容量未谈。 |
| ⑧失效条件 | 无。"背驰修复"没有可判真假的定义。 |
| ⑨与我的适配 | 无法评估：前八格一半以上缺失，说明它目前不是一套规则，而是一段话术。 |

答案之外的结论：九格里缺了六格，这张卡自己就给出了处置——不进实盘线，最多进入学习线的观察名单；观察的第一件事是把它翻译成可判真假的规则（〔B6-C04〕），翻译不出来，就到此为止。

### 五、使用纪律与三条提醒

第一，深拆与粗扫分层：时间盒内深度拆解 2~3 个门派，其余用同一张卡粗扫一遍即可（〔B8-C10〕）；粗扫也用九字段，只是每格允许写"未查"。

第二，卡片是学习线工具：按体用分离（〔B8-C01〕），填卡不产生任何下单资格；从卡片到实盘之间隔着翻译、验证、前向三道闸（〔B8-C09〕）。

第三，不对号入座：本书的练习只用虚构话术，不评价任何真实流派与真实人物；你自己的笔记里同样只拆"方法描述"，不拆"人"——拆人拆不出规则。

## 常见误区

**误区一："九格都填满了，说明方法完整，可以上实盘。"**

- **为什么错：** 完整与有效是两道门（〔B1-C06〕、〔B8-C01〕）。九格填满只说明描述完整；是否有效由证据强度与验证结果决定（〔B6-C12〕）。示范卡的证据强度只能填 B，正是因为还差样本外与前向。
- **正确做法：** 填卡只授予"可检验"资格；实盘资格由九步验证与前向小资金发放（〔B6-C11〕）。

**误区二："收益来源写'主力资金介入'，说明有人大笔买入，这就是来源。"**

- **为什么错：** 五类收益来源（〔B1-C02〕）里没有"主力资金"这一类；它无法核验，也说不清对手盘为什么持续让利。凡是不能落到五类之一、写不出对手盘的说法，按"说不清则不采信"处理。
- **正确做法：** 追问一句"这笔钱从谁身上来、他为什么给"，答不上就在第①格填"写不出"，整卡降级。

**误区三："证据强度 D 的方法一定亏钱，所以拆都不用拆。"**

- **为什么错：** 分级评的是"凭什么相信"，不是"结果一定如何"。D 级方法偶尔赚钱完全可能，那通常只是运气（〔B6-C02〕的方差）；反过来，证据强也不承诺赚钱。跳过拆解，就失去了区分"说不清"与"讲得清但未验证"的能力。
- **正确做法：** D 级方法不进实盘线，但可以进学习线；对它做的第一件事是尝试翻译成客观规则，翻译不出就归档。

## 本章小结

1. 拆解卡＝九字段格式化表格，概念归属本章；它看穿的是结构，不是盈亏。
2. 九字段：收益来源（含对手盘）、5+1 调用、配平方式、风控方式、退出条件（映射七种退出）、证据强度（A–D）、成本与容量、失效条件、与我的适配。
3. 填写三默认：写不出就填"写不出"；风控参数以册三为准；宣传话术默认 D。
4. 示范卡（门派 C）的全部参数与〔B8-C05〕一致，均为待验证假设。
5. 填满不等于有效；拆解卡是学习线工具，实盘资格来自验证与前向。

## 自测题

**题 1（字段功能）。** 拆解卡第⑥字段填 D，意味着什么？D 级方法还能不能进实盘线？

**答案与解析：** D 表示证据只有故事、个案、口述（分级深讲在〔B6-C04〕），不构成"有效"的证据。按体用分离（〔B8-C01〕），D 级方法最多进学习线观察，不进实盘线；若想采信，先翻译成可判真假的规则（〔B6-C04〕），再走九步验证（〔B6-C12〕）。

**题 2（收益来源归类）。** 给四段描述归入五类来源（或判"写不出"）：A"承担指数长期波动，换取补偿"；B"在别人恐慌抛售时接货"；C"利用交易机制中对手被迫按规则成交的环节"；D"跟着老师买，老师水平高"。

**答案与解析：** A 是风险溢价；B 是行为偏差（也可能叠加流动性提供，须写清对手盘为什么卖）；C 是制度与结构约束（若落在接单与让价环节，也可写流动性提供，按机制写清即可）；D 写不出——"老师水平高"不在五类之内，无法核验，按〔B1-C02〕规则不采信。

**题 3（证据强度定级）。** 给四个描述定级：①机械规则，样本外通过，成本已计入；②"我用这方法三年，赚了不少"（无记录）；③检查表加决策日志的自由裁量方法；④机械规则，但没做样本外。

**答案与解析：** ①A；②D；③C（自由裁量型的上限就是 C）；④B。注意①的 A 只说明证据结构合格，不承诺未来有效。

**题 4（退出映射）。** 某方法只写了"跌破买入逻辑位就卖"。这一条对应七种退出中的哪一种？作为一张合格的拆解卡还缺什么？

**答案与解析：** 对应①开仓逻辑被证伪（止损）。还缺账户级与生活级的共同条款：⑥熔断强制减仓/平仓、⑦账户外现金需求（〔B3-C09〕）。若方法本身没有其他退出（目标、时间、换仓、再平衡），第⑤格应如实写"仅①＋共同条款"，不能替方法脑补。

**题 5（综合判断）。** "拆解卡九格都填满了，说明这个方法有效，可以上实盘。"这句话有两个错误，请指出。

**答案与解析：** 其一，完整不等于有效（〔B1-C06〕）：九格填满只说明描述完整，有效性由证据强度与验证结果决定（〔B6-C12〕）。其二，第⑨格"与我的适配"即使匹配也不构成推荐——适配只是事实核对；赚不赚钱取决于方法是否有效，这一点卡片回答不了。

**三条默认值**
